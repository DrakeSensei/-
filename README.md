# تقویم خورشیدی (Persian Solar Hijri Calendar)

یک اپلیکیشن اندروید سبک، سریع و کاملاً آفلاین ساخته‌شده با **Kotlin** و **Jetpack Compose**.

## ویژگی‌ها
- 📅 **تقویم هجری خورشیدی**: نمایش دقیق روز، ماه، سال و روز هفته به فارسی
- 🌍 **معادل میلادی**: تبدیل آنلاین و بدون نقص با اسامی ماه‌های میلادی به فارسی و انگلیسی
- ⏰ **ساعت ۲۴ ساعته**: با ارقام فارسی
- 🔔 **اعلان نوار وضعیت (Status Bar Notification)**: نمایش تاریخ روز بدون مصرف باتری و با قابلیت شروع مجدد خودکار پس از روشن شدن دستگاه (BOOT_COMPLETED)
- 🌙 **پوسته روشن و تاریک**: طراحی مدرن بر پایه Material 3
- 🛡️ **حفظ حریم خصوصی**: بدون دسترسی اینترنت (`NO INTERNET PERMISSION`)
- ⚡ **فوق‌العاده بهینه**: بدون کتابخانه‌های سنگین خارجی یا سرویس‌های پس‌زمینه دائم

## ساخت APK با GitHub Actions (بدون نیاز به کامپیوتر)
این پروژه شامل ورک‌فلو آماده GitHub Actions است:
1. پروژه را در مخزن گیت‌هاب (GitHub Repository) خود پوش کنید.
2. به تب **Actions** در گیت‌هاب مراجعه کرده و **Build Android APK** را انتخاب کنید.
3. دکمه **Run workflow** را بزنید.
4. پس از اتمام فرایند ساخت (حدود ۲ دقیقه)، فایل‌های APK در بخش **Artifacts** به صورت مستقیم قابل دانلود هستند:
   - `MyCalendar-Debug-APK`
   - `MyCalendar-Release-APK`

## ساخت با Android Studio یا خط فرمان
```bash
./gradlew assembleDebug
# فایل خروجی در app/build/outputs/apk/debug/app-debug.apk ذخیره می‌شود
```
